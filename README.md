# CLAQUETTE

منصة إدارة النقدية والمبيعات والمخزون والجرد للمنشآت.

Cinema operations platform — petty cash, box office sales, inventory and stocktaking.

## Brand

- Name: **CLAQUETTE**
- Business: cinema / box office
- Tone: formal luxury cinema
- Palette: ink black `#0B0A09`, antique gold `#C9A227`, ivory `#F5E6C8`
- Interface: Arabic RTL, English wordmark

## Modules

- Petty cash — صندوق الشباك
- Sales — التذاكر والمبيعات
- Stocktaking — الجرد
- Inventory — المخزون
- Reports — التقارير

## Catalog

Product list is empty on purpose. SKUs and images will be added from the operator.
