# CLAQUETTE

منصة إدارة النقدية والمبيعات والمخزون والجرد للمنشآت.

Formal platform for petty cash, sales, inventory and stocktaking.

## Brand

- Name: **CLAQUETTE** (English lockup)
- Tone: formal luxury cinema
- Palette: ink black `#0B0A09`, antique gold `#C9A227`, ivory `#F5E6C8`
- Interface: Arabic RTL first, English brand mark

## Modules

- Petty cash — الصندوق النثري
- Sales — المبيعات
- Stocktaking — الجرد
- Inventory — المخزون
- Reports — التقارير

## Intended stack

- Next.js 15 + React 19
- Tailwind CSS v4 + shadcn/ui (RTL)
- next-intl
- Framer Motion
- TanStack Table + TanStack Query
- Recharts
- Zustand
- Zod + React Hook Form
- Prisma + PostgreSQL
- Lucide icons
- IBM Plex Sans Arabic
